## 🧭 我的工作方式

- **一技能一仓库**：每个技能 = SKILL.md 入口 + references 知识规范 + scripts 校验脚本 + tests 双样例
- **可验证优先**：校验脚本统一 Python，标准退出码（0 通过 / 1 错误 / 2 警告），good/bad 双样例必须同时断言
- **持续学习**：每轮任务收尾把经验沉淀为技能与校验资产
